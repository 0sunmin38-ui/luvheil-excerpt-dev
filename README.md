# 채팅 발췌기

단일 HTML 파일로 동작하는 채팅 발췌 도구.

**https://0sunmin38-ui.github.io/luvheil-editor/**

## 실행

```bash
./serve.sh          # http://localhost:8765 로 띄운다
```

`index.html` 을 파일로 직접 열어도 대부분 동작하지만, **함께 들어 있는 글꼴
(조선일보명조 · 조선신명조 · 부크크명조 · 코펍월드돋움)은 서버로 띄워야 한다.**
브라우저가 `file://` 에서 온 글꼴 파일을 CORS 로 막아 화면에도 안 뜨고 이미지 저장에도
안 박힌다. 웹에서 받아 쓰는 글꼴(프리텐다드 · 본고딕 · 나눔 · 모나 · 갈무리)은 무관하다.

## 구조

| 경로 | 설명 |
| --- | --- |
| `index.html` | 마크업·스타일·스크립트가 모두 들어 있는 단일 파일 |
| `font/web/` | 함께 들고 다니는 한글 글꼴 (woff2 + 각 글꼴의 `@font-face` CSS) |
| `serve.sh` | 로컬 서버 실행 |

### 글꼴

`font/web/*.woff2` 는 원본 otf/ttf 를 한글 음절 전체 + 자모 + 라틴 + 문장부호로
서브셋해 구운 것이다. CSS 안의 경로는 **그 CSS 파일 기준 상대경로**(`./XXX.woff2`)로
적는다 — 루트 기준(`/font/web/…`)으로 적으면 저장소를 하위 경로에 올렸을 때 어긋난다.

글꼴을 더하려면 `font/web/` 에 woff2 와 `@font-face` CSS 를 넣고 `index.html` 의
`FONTS` 배열에 한 줄 더하면 된다. `@font-face` 하나에 url 은 하나만 둔다 — 이미지 저장이
블록 안의 url 을 전부 인라인하기 때문에 ttf 를 같이 적어 두면 그것까지 통째로 박힌다.

> 글꼴 파일의 재배포 조건은 각 글꼴의 라이선스를 따른다. 저장소를 공개로 두기 전에
> 한 번 확인할 것.

## 수정 방법

1. `index.html` 을 편집한다.
2. 브라우저에서 새로고침해 확인한다.
3. 커밋·푸시한다.

```bash
git add -A
git commit -m "설명"
git push
```
