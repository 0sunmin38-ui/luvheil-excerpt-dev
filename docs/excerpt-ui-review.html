레퍼런스에서 가져올 원리

  • Shoong의 청회색 미리보기는 흰 편집 패널과 명확히 구분되고, 보기 도구는 하단에 모인다. 사과 발췌기에서는 Mint·Pear 그라데이션과 십자 표시로 작업 영역의 인상을 만든다. Shoong
  • Chat2Img는 떠 있는 둥근 툴바와 카드별 표면을 사용한다. 여기서는 배율 바에 반투명 표면을 쓰고, 글을 오래 읽는 설정 영역에는 불투명 표면을 쓴다. Chat2Img
  • 십자만 반복해도 격자가 읽힌다. 22px마다 같은 크기의 4px 십자를 놓고 선 색을 옅게 적용한다. 캔버스 모서리 표시는 실제 비율과 함께 움직이고, 뒷판의 그리드는 화면 기준으로 고정한다. Portfolio Kit의 cross 패턴
  • 하단 툴바에 배율을 두면 조작 위치가 일정하다. 사과 발췌기에서는 미리보기 영역의 가로 중심에 바를 고정한다. Framer 캔버스 도구

영역별 디자인 변경안

영역현재 코드제안
앱 바.topbar, .brand투명 배경에 현재 서비스 이름을 표시한다. 앱 바 근처에서 십자 밀도는 유지하고 색을 옅게 한다. 투명 표면에서도 저장 버튼은 진녹색으로 읽힌다.
미리보기 작업 영역
미리보기 뒷판		#stage, .shell현재 index.html의 Mint --c-primary: #84BF93와 Pear --c-secondary: #F3EEB6를 사용한다. 좌상단은 Mint 27%, 우하단은 Pear 48%를 아이보리에 섞어 적용한다.
배율·맞춤 바
선택 작업 바		#previewZoom, #bulkRowTop배율·맞춤 바만 PC 미리보기 하단에 고정한다. 기존 모바일 숨김 동작을 유지하고 선택 작업 바는 현재처럼 상단에서 나타난다. PC에서 바 높이만큼 스크롤 여백을 확보한다.
배율 래퍼
출력 캔버스		#canvasFit, #canvas옅은 십자 표시 네 개와 실제 비율을 래퍼의 화면 표시용 레이어에 둔다. 비율을 바꾸면 표시가 모서리를 따라간다. 투명한 PNG에도 출력 배경과 테마의 설정이 그대로 반영된다.
출력 배경·장식·본문.cv-bg, .cv-frame, .cv-head, .blk, .canvas-signature출력 배경은 편집기 뒷판과 별개로 테마에서 설정한다. 직접 편집 가능한 장식과 블록은 가는 녹색 포커스 링으로 선택 상태를 보여준다.
작성 카드·서식 바
결과물 설정		#sheet, #dock, #formatWrap, #settingsPanel아이보리 표면, 1px 테두리, 10~14px 모서리. 활성 탭에 연녹색을 쓰고 글 입력과 서식 바를 하나의 카드처럼 붙인다.
저장 버튼·알림#btnSave, #saveSheet, #toast진녹색 단색 표면에 얕은 바깥 그림자를 적용한다. 누르면 버튼이 1px 내려간다. Apple 버튼 가이드 · Apple 소재 가이드

SVG와 움직임

  • 아이콘은 20~24px 그리드로 맞춘다. 가로·세로 맞춤 아이콘은 각진 ㄱ자 모서리와 방향 표시를 사용한다.
  • 호버·선택은 약 140ms 동안 배경색을 바꾼다. 그리드는 스크롤과 확대 중에도 고정한다.
  • 보기 전환은 맞춤 버튼을 눌렀을 때 약 170ms로 적용한다. 드래그·휠·연속 확대에는 동작을 지연시키지 않고, 모션 감소 설정에서는 즉시 반영한다.
