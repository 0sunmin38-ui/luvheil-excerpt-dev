# 모바일 판형 계획 대비 후속 점검

기준: 2026-11-05. 아이폰에서 기존 카카오 테마의 헤더가 본문 크기를 따라 변한다는 제보를 받고 계획과 구현을 다시 대조했다.

## 확인한 불일치와 조치

| 항목 | 확인 결과 | 조치 |
| --- | --- | --- |
| 기존 카카오 헤더 | 기존 테마 보존을 위해 본문 크기와 연동된 채였다. 앞선 검사는 새 `모바일 읽기`의 바깥 헤더 글자만 측정해 이 차이를 보여주지 못했다. | 제공된 3:4 캡처를 검토한 뒤 카카오·인스타 DM을 판형 기준 고정 헤더로 변경했다. 400px에서 14px/64px, 560px에서 20px/약 91px이다. 기존 출력의 헤더 크기와 페이지 점유 높이는 달라진다. |
| 서명·음악·다른 헤더 | 새 시안의 서명은 고정됐지만 음악 제목은 본문을 따랐고, 새 시안에서 헤더 유형을 바꾸면 크기 고정이 풀렸다. | 서명과 음악 글씨 크기를 선택적으로 고정했다. 7종 헤더 전부의 글자 기준을 본문과 분리하고, 높이·글씨·SVG 아이콘 크기를 유형별로 조절하도록 확장했다. 기존 출력의 헤더 크기·페이지 점유는 달라질 수 있다. |
| 테스트 서버 공개 범위 | 기존 `python -m http.server`가 `.git/config`까지 Wi‑Fi에 제공했다. | 서버를 앱과 번들 웹 글꼴만 제공하도록 바꾸고 이전 서버를 종료했다. 앱·글꼴 200, 저장소 파일·상위 경로 404를 확인했다. |
| 이전 저장본 | 새 모바일 시안을 이미 저장한 v22 데이터에는 음악 크기 기준이 없다. | v23에서 이 시안에만 누락된 기본값 14px을 보충한다. 기존 테마·사용자 값은 유지한다. |

## 계획에서 아직 완료되지 않은 검증

- **변경 전 기준선:** 원래 계획의 전체 대표 입력 세트와 320·360·390px 실물 PNG를 사전에 고정하지 못했다. 현재 비교 PNG는 짧은 대화 한 세트다.
- **실기 가독성:** 자동 WebKit은 실제 iPhone Safari의 사진·파일 앱 확대 상태, 공유 시트, 키보드·회전 동작을 증명하지 못한다. 320px 편집 미리보기는 0.72배라 논리 18px 본문이 약 13px로 보인다.
- **콘텐츠 경계:** 매우 긴 한글·영어·이모지 한 블록의 자동 분할, 극단적으로 긴 원본 이미지, 배경 이미지 `cover`의 중요한 부분 잘림은 아직 사례별 대조가 없다.
- **다른 저장 경로:** Android의 직접 DOM 캡처, Windows의 글꼴 대체·OS 배율, Mac Safari의 첫 캡처 예열을 실기에서 확인하지 못했다.
- **정확한 비율:** 3:4 논리 높이를 정수 533px로 계산해 저장 PNG가 1440×1918px이다. 수학적으로 정확한 3:4보다 높이 2px이 짧다. 현재 결과의 줄바꿈·비율 체감에는 영향이 작으나, 정확한 픽셀 비율이 필요한 게시 대상이 확인되면 출력 크기 정책을 별도로 조정해야 한다.

## 변경 영향 범위

- `shortSide`가 없는 과거 테마는 560px이다. 내용 맞춤과 Cyworld 고정 4:3은 자동 검사에서 이전 폭을 유지했다.
- 새 장식 크기 필드는 10~40px 범위만 렌더에 반영한다. JSON 가져오기의 비정상 값이 헤더·서명을 무한히 키우지 않도록 제한했다.
- iMessage·Kakaotalk·Instagram DM·Bubble·e-Book·Lock Screen·Article 헤더의 글자 기준은 본문과 분리됐다. `헤더 높이(px)`·`장식 글씨 기준(px)`·SVG가 있는 유형의 `SVG 아이콘 크기(%)`를 유형별로 저장한다. 이전에 직접 지정한 헤더 글자 크기는 새 유형별 값을 지정하기 전까지 보존한다.
- 헤더 높이는 정확한 높이이며 내용이 더 크면 잘릴 수 있다. iMessage의 하단 선은 높이를 바꿔도 맨 아래에 놓이고, 다른 헤더의 내용은 가운데에 놓인다. 고정형 헤더의 시작점은 0px이며 이전 `top` 저장값은 무시한다. Article은 본문 흐름에서 시작한다. 페이지 분할과 뒤 장 헤더 사본은 새 높이를 반영한다.
- `shortSide`의 편집 스텝퍼는 제거했다. 테마의 400/560px 기본값과 이전 설정 JSON의 명시값은 계속 반영한다. 내용 맞춤 폭 조절은 유지된다.
- Wi‑Fi 서버는 읽기 전용 앱 제공만 한다. 앱의 외부 CDN 글꼴과 PNG 라이브러리는 여전히 인터넷 연결에 의존하므로 첫 저장·오프라인 사용은 별도 확인이 필요하다.
