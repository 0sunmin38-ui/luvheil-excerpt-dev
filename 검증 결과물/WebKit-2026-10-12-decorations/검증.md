# Safari 장식 저장 2차 검증

2026-10-12. Playwright WebKit 26.5 / Chromium 151. 실제 iPhone Safari 결과와 구분한다.

- 기본 조건: 390×844 모바일 뷰포트, iPhone UA, DPR1440/560, 논리 캔버스560px. 윤도 대사5개, iOS/insta DM 프리셋. 색 격자는 회전·흐림·위치 대조용 합성 배경이다.
- `webkit-before-*`: 수정 전 실제 exportPNG의 첫 출력. 인스타/알림의 오른쪽 그림자 밀림, iOS 첫 출력 배경·시계 누락이 보임.
- `webkit-verified-*`: 수정 후 실제 exportPNG. 배경·글래스·그림자를 SVG 밖의 최종 Canvas에 합성. 여러 장/2단/프레임 대표 출력 포함.
- `webkit-after-*-screen`: 화면 대조 참고. 모서리6px는 앱의 미리보기 규칙이며 저장본은 기존대로 직각.
- `webkit-verified-results.json`: 최종 공유·복구 검사를 추가한 WebKit15조합/21장 결과. `paint`에 표면 공유 수, 임시 상태 정리, 그림자 복구 결과가 있음.
- `chromium-final-results.json`: Chromium15조합/21장 결과.
- `chromium-android-results.json`: Android UA로 라이브 저장 분기5조합/10장 및 상태 복구 검증. 실제 Android 기기 검증이 아님.
- `webkit-policy.json`: HTTP404 외부 이미지 누락 안내 후 1장 저장, 잘못된 로컬 PNG는 오류 안내 후0장. 요청 가로채기로 만든 CORS 응답은 CORS 성공/실패의 판정 근거로 사용하지 않음.

PNG 생성 성공과 실제 기기의 완전 일치는 구분한다. iPhone 실기 재확인이 필요하다. 검증·선택 이유·비용·남은 항목은 변경사항.md의16-2~4와2차 검증 절에 기록했다.
