# 대사 스타일 비교 PNG

각 PNG는 앱의 **PNG 저장 기능**으로 만든 결과물이다. 한 이미지에 ① 3단어 이내, ② 한 줄을 채운 대사, ③ 자동 줄바꿈으로 3줄이 된 영어 대사, ④ 자동 줄바꿈으로 3줄이 된 영어 원문과 작은 한글 번역, ⑤ 같은 화자의 연속 대사 3개, ⑥ 자동 줄바꿈으로 3줄이 된 한글 대사를 넣었다. ③·⑥에는 수동 줄바꿈이 없고 ④에는 영어 원문과 번역 사이에만 수동 줄바꿈 한 번이 있다. 번역 등 대사 속 작은 한글에만 `글자 크기 작음` 세부 서식(`[-]…[/-]`)을 적용했다. 실제 이미지 형식의 프로필을 사용했다. 캔버스는 내용 맞춤, 논리 폭 440px이며 PNG는 1440px 폭이다.

③·④·⑥은 각 스타일의 실제 폭에서 문장이 자동으로 3줄이 되는 조합을 선택했다. 스타일에 따라 문장 길이와 번역 표현이 조금씩 다르다. 이제 영어 단어를 보존하고 한글은 필요할 때 음절 사이에서 끊는 혼합 줄바꿈을 사용한다. 인용은 프로필과 간격을 제외한 본문 영역 전체를 쓴다.

검증: `render-all.cjs`를 실행해 Chromium에서 PNG 10장을 내보내고, ③·④의 영어와 ⑥의 한글이 각 스타일에서 실제 3줄인지, 수동 줄바꿈 개수가 각각 0·1·0인지 검사했다. Chromium·WebKit에서 여섯 대사 유형 모두 스타일 선택 후 대사 묶기가 켜지며 실제 연속 대사에 적용되는지도 확인했다. 인용은 좌측·우측·프로필 없는 경우 모두 사용 가능한 본문 폭을 채우는지 두 브라우저에서 검사했다. 한글 서식의 글자 크기 감소, 프로필 크기, 각본·없음·알림의 간격도 검사했다. 측정값은 [measurements.json](measurements.json)에 있다.

이번 확인에서는 각본·없음의 프로필을 첫 대사에만 표시하고, 한 줄·긴 영어·긴 한글 대사에서 프로필의 행 기준 위치가 같도록 검사했다. 비교 이미지는 위 표의 `script.png`, `none.png`를 보면 된다.
