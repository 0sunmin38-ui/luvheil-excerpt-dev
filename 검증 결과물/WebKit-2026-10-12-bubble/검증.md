# Bubble 검증

- 참고: 버블/버블.JPG, 버블/버블로고.png.
- WebKit 자동 검증: 헤더 두 입력값과 로고 로딩, 좌상단 2px·나머지 18px, 원형 프로필 강제 적용, 대사 묶기, 태그 켜기/끄기 및 색상 변경 통과.
- 설정 화면: Bubble 선택지와 로고 옆 문구 입력, 태그 색상 선택 존재. 라운드 프로필 토글 미표시, 태그 비활성화 시 색상 선택 미표시 확인.
- 우측 말풍선은 좌우 반전(우상단 2px).
- PNG 1장 생성 및 시각 확인. 헤더 그림자는 기존 저장 합성 경로 사용. 실행 중 JavaScript 오류 없음.
- 실제 iPhone 기기 검증은 수행하지 않음.
- 화면 이미지는 묶기 꺼짐·기본 분홍, 저장 이미지는 묶기 켜짐·보라 태그 상태.

## 색상·프로필 보완

- 헤더 글자와 SVG는 기본 글자색 사용. 로고는 선택한 아티스트 색 사용, 미설정이면 기본 글자색 사용. 원본 로고 알파 마스크로 색상만 적용.
- 프로필은 사진 → 흰색 여백 2px → 바깥 링 2px 순서로 분리.
- 링과 ARTIST 태그는 선택 색 → 흰색 60%를 섞은 밝은 색의 115도 그라데이션 공유.
- WebKit에서 실제 사진 요소, 흰 여백, 링·태그 그라데이션, 로고 색 및 PNG 저장 확인.

- 비율 보완: Bubble 프로필 28px → 36px, ARTIST 글씨 이름 대비 75% → 90%, 이름 굵기 700. WebKit 계산 스타일 및 PNG 생성 확인.

- 추가 비율 조정: 이름 본문 대비 80% → 90%, 프로필 36px → 38px. CSS 수정 및 diff 검사 완료; 이 최종 크기의 WebKit 재검증은 수행하지 않음.

- 숫자 표시 보완: `+` 고정, 숫자만 입력·붙여넣기 허용. 기존 문구에서 숫자만 추출. 기존 등록 글꼴 IBM Plex Sans KR(IBM 플렉스 산스)을 숫자에 지정하고 저장 임베드 목록에 포함. WebKit 숫자 정제·계산 글꼴·PNG 생성 검증 통과. 최신 이름 비율·38px 프로필도 재검증 완료.

- 최종 기본 테마: Bubble 하나, 연회색 배경·흰색 좌우 말풍선. 버전 14의 색 테마 6종 제거, 사용자 테마 유지 및 활성 선택 전환 검증 통과. WebKit PNG 1장 생성, 삭제 후 재로드에서 삭제 유지, JavaScript 오류 없음.

- 좌우 구분 보완: ARTIST 태그·흰 여백·그라데이션 링은 좌측에만 적용. 우측은 원형 프로필만 표시. WebKit 좌측 태그 2개·우측 태그 0개, 우측 링 없음 및 원형 유지, PNG 저장 통과.
